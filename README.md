# flutter-book-code

Исходники к книге «Разработка мобильных приложений на Flutter» — код каждой главы отдельной папкой.

## Что внутри

- `chapters/` — двадцать папок, `ch01-hello_flutter` … `ch20-release`. В каждой README.md с описанием файлов.
- `projects/` — три готовых проекта целиком, их можно открыть в редакторе и запустить сразу:
  - `hello_flutter` — глава 1;
  - `widget_playground` — песочница глав 9–13;
  - `quiz_app` — «Викторина», главы 14–20.

## Как пользоваться

**Главы 2–8** — программы для [DartPad](https://dartpad.dev): откройте файл, скопируйте код, нажмите Run. Один файл — один раздел главы.

**Главы 1 и 9–20** — файлы Flutter-проекта (`lib`, `test`, `assets`, `pubspec.yaml`)
в состоянии на конец главы. Чтобы запустить, создайте проект с тем же именем
(Flutter: New Project → Application), скопируйте файлы поверх своих и выполните:

```
flutter pub get
flutter run
```

Или возьмите проект из `projects/` — там всё уже на месте.
