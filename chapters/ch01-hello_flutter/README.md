# Глава 1. Привет, Flutter!

Проект `hello_flutter` — стартовый шаблон Flutter после двух правок из главы: `title: 'Моё первое приложение'` и `MyHomePage(title: 'Считалка')`. Комментарии шаблона убраны, чтобы код было легче сравнивать со своим.

- `lib/main.dart` — приложение-счётчик.
- `test/widget_test.dart` — тест, который Flutter создал вместе с проектом (глава 19 объяснит, что это).
- `pubspec.yaml` — паспорт проекта.

Чтобы запустить: создайте проект `hello_flutter` (Flutter: New Project → Application), скопируйте в него папки и файлы отсюда поверх своих, выполните `flutter pub get` и запустите. Или возьмите готовый проект целиком: [`projects/hello_flutter`](../../projects/hello_flutter).
