# Глава 2. Первые программы на Dart

Программы для DartPad (dartpad.dev): откройте файл, скопируйте содержимое в левое окно, нажмите Run. Один файл — один раздел главы, по порядку.

- `01_hello.dart` — первая программа.
- `02_variables.dart` — переменные.
- `03_var_final_const.dart` — var, final, const и типы данных.
- `04_interpolation.dart` — подстановка значений в строку.
- `05_arithmetic.dart` — арифметика, короткие записи, комментарии.
- `06_typo_error.dart` — программа с ошибками, нарочно: прочитайте, что скажет DartPad, и почините.
- `07_business_card.dart` — программа-визитка.
