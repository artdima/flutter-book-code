# Глава 3. Как программа принимает решения

Программы для DartPad, по разделам главы.

- `01_comparisons.dart` — операторы сравнения и bool.
- `02_if.dart`, `03_if_else.dart`, `04_else_if.dart` — условия.
- `05_and_or_not.dart` — `&&`, `||`, `!`.
- `06_ternary.dart` — тернарный оператор.
- `07_switch.dart` — switch/case.
- `08_weather_advisor.dart` — мини-проект: советчик по погоде.
- `09_years_word.dart` — «мне 21 год»: склонение через остаток от деления.
