# Глава 4. Циклы: компьютер не устаёт повторять

Программы для DartPad, по разделам главы.

- `01_for.dart`, `02_for_step.dart` — цикл for, обратный отсчёт, шаг.
- `03_for_in.dart` — for-in по списку.
- `04_while.dart` — while и do-while.
- `05_break_continue.dart` — выйти из цикла или пропустить виток.
- `06_nested_tree.dart` — ёлочка из звёздочек (вложенные циклы).
- `07_scope.dart` — область видимости переменных.
- `08_guess_number.dart` — мини-проект: компьютер угадывает число двоичным поиском.
