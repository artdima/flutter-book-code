# Глава 5. Списки и словари

Программы для DartPad, по разделам главы.

- `01_list_and_index.dart` — список и индексы с нуля.
- `02_add_remove.dart` — add, insert, remove, removeAt, addAll.
- `03_properties.dart` — length, isEmpty, first, last.
- `04_iterate.dart` — перебор: for-in, for со счётчиком, forEach.
- `05_where_map.dart` — конвейер where и map.
- `06_sort.dart` — сортировка, в том числе по убыванию.
- `07_map.dart` — словарь Map.
- `08_set.dart` — множество Set.
- `09_shopping.dart` — мини-проект: покупки ко дню рождения.
