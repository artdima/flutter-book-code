# Глава 6. Функции — команды, которые вы придумали сами

Программы для DartPad, по разделам главы.

- `01_greet.dart` — первая своя функция.
- `02_parameters.dart` — параметры и аргументы.
- `03_named_parameters.dart` — именованные параметры, required, значения по умолчанию.
- `04_return.dart` — возврат значения и ранний return.
- `05_years_word.dart` — склонение из главы 3, упакованное в функцию.
- `06_arrow.dart` — стрелочные функции.
- `07_anonymous.dart` — анонимные функции в where, sort, forEach.
- `08_recursion.dart` — рекурсия с условием выхода.
