# Глава 7. Классы и объекты

Программы для DartPad, по разделам главы. В каждом файле — свой вариант класса `Pet`, как в соответствующем разделе.

- `01_class_pet.dart` — класс, поля, методы, объекты.
- `02_constructor.dart` — конструктор и `this`.
- `03_named_constructor.dart` — именованный конструктор `Pet.newborn`.
- `04_tostring.dart` — toString и @override.
- `05_inheritance.dart` — наследование: Pet, Cat, Dog.
- `06_enum.dart` — перечисление и switch.
- `07_quiz_classes.dart` — мини-проект: классы Question и GameResult для будущей викторины.
