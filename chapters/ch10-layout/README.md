# Глава 10. Расставляем всё по местам

Экраны песочницы `widget_playground` из этой главы.

- `lib/screens/layout_demo_screen.dart` — Column, Row, выравнивание, переполнение, Expanded, Stack.
- `lib/screens/list_demo_screen.dart` — ListView.builder и ListTile.
- `lib/screens/grid_demo_screen.dart` — GridView.count.
- `lib/screens/profile_screen.dart` — мини-проект: карточка героя.
- `lib/widgets/stat_bar.dart` — шкала характеристики из двух Expanded.

Чтобы запустить экран, подставьте его в `home:` в `main.dart` (глава 9) или откройте из меню готовой песочницы.

Чтобы запустить: создайте проект `widget_playground` (Flutter: New Project → Application), скопируйте в него папки и файлы отсюда поверх своих, выполните `flutter pub get` и запустите. Или возьмите готовый проект целиком: [`projects/widget_playground`](../../projects/widget_playground).
