# Глава 11. Кнопки, ввод и состояние

Экраны песочницы `widget_playground` из этой главы.

- `lib/screens/counter_screen.dart` — счётчик своими руками: StatefulWidget и setState.
- `lib/screens/greeter_screen.dart` — TextField, контроллер, dispose, проверка ввода.
- `lib/screens/controls_screen.dart` — кнопки всех видов, Switch, Checkbox, Slider.
- `lib/screens/magic_ball_screen.dart` — мини-проект: магический шар.

Чтобы запустить: создайте проект `widget_playground` (Flutter: New Project → Application), скопируйте в него папки и файлы отсюда поверх своих, выполните `flutter pub get` и запустите. Или возьмите готовый проект целиком: [`projects/widget_playground`](../../projects/widget_playground).
