# Глава 13. Формы: собираем данные от пользователя

Экран главы для песочницы `widget_playground`.

- `lib/screens/survey_screen.dart` — мини-проект «Анкета участника»: `Form`, `TextFormField` с валидаторами, выпадающий список, галочка согласия, карточка с итогом и сброс формы.

Подключается как `home` в `main.dart` — или, если песочница уже с навигацией, маршрутом `/survey`.
