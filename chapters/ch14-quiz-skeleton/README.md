# Глава 14. Задумка и каркас приложения

Проект `quiz_app` на конец главы: модель, данные, стартовый экран и заглушки игры и результата.

- `lib/main.dart` — запуск, тема, маршруты.
- `lib/models/question.dart` — класс Question.
- `lib/data/questions.dart` — встроенные вопросы.
- `lib/screens/start_screen.dart` — стартовый экран.
- `lib/screens/game_screen.dart`, `result_screen.dart` — заглушки, чтобы проект собирался насквозь.

Чтобы запустить: создайте проект `quiz_app` (Flutter: New Project → Application), скопируйте в него папки и файлы отсюда поверх своих, выполните `flutter pub get` и запустите. Или возьмите готовый проект целиком: [`projects/quiz_app`](../../projects/quiz_app).
