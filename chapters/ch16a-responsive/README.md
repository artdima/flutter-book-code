# Глава 16. Приложение на любом экране

Экран главы для песочницы `widget_playground`.

- `lib/screens/responsive_screen.dart` — мини-проект: карточка героя из главы 10, которая на широком экране перестраивается из столбика в две колонки. `LayoutBuilder`, брейкпоинт 600, `AspectRatio`, `FittedBox`, `Wrap`, ограничение ширины через `ConstrainedBox`.

Переиспользует `lib/widgets/stat_bar.dart` из главы 10. Смотреть нужно, меняя ширину окна: сожмите и растяните.
