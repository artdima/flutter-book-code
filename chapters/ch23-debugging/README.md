# Глава 23. Когда что-то идёт не так

Проект `quiz_app` с тестами из главы. Запуск: `flutter test`.

- `lib/utils/years_word.dart` — функция yearsWord из главы 6.
- `test/years_word_test.dart` — тест склонения из текста главы.
- `test/widget_test.dart` — ещё три проверки: isCorrect, поездка Question в JSON и обратно, выключенная AnswerButton.

Чтобы запустить: создайте проект `quiz_app` (Flutter: New Project → Application), скопируйте в него папки и файлы отсюда поверх своих, выполните `flutter pub get` и запустите. Или возьмите готовый проект целиком: [`projects/quiz_app`](../../projects/quiz_app).
