Звуки викторины (глава 18).

correct.mp3  — два восходящих «динь», 0,6 с. Играет в _onAnswer при верном ответе.
wrong.mp3    — короткий низкий «бззз», 0,4 с. При неверном.
fanfare.mp3  — арпеджио и аккорд, 1,4 с. Для нового рекорда — задание 2 главы 18.
fail.mp3     — два нисходящих «уа-уа», 0,9 с. Для провала — то же задание.

Все четыре синтезированы для книги (синус с обертонами, без чужих сэмплов):
можно свободно использовать, менять и раздавать вместе с приложением.
Исходник генерации — example/assets-src/make_sounds.py.

В коде путь пишется без префикса assets/: AssetSource('sounds/correct.mp3').
